SCAMP Tutor
===========

A do-it-yourself AI tutor for SCAMP. It works with whatever AI assistant you already use — Claude,
ChatGPT, Gemini, or anything that can read a web page.

There's nothing to install. You just paste a short prompt that points the assistant at a set of
instructions and the full SCAMP documentation and examples. The tutor is built to help you
*understand and own* what you make — not to write your piece for you.

How to use it
-------------

Copy the prompt below into a fresh chat with your AI assistant. Replace the four numbers with your
own experience levels (1 = none, 10 = expert) so it can pitch explanations at the right level, then
start asking it to help you make music.

.. code-block:: text

    Read https://marcthespark.github.io/scamp-tutor/tutor.txt. I want you to be my SCAMP tutor,
    using the instructions and resources described there. On a scale from 1-10, my experience
    levels are as follows: coding 5, python 4, music theory 7, scamp libraries 2.

Be honest about your levels — they only change how much gets explained, never what you're allowed
to do.

Just want an assistant that knows SCAMP, without the teaching? Point it at
`resources.txt <https://marcthespark.github.io/scamp-tutor/resources.txt>`_ instead.

The tutor's instructions and resources live at https://marcthespark.github.io/scamp-tutor/
(source: `scamp-tutor on GitHub <https://github.com/MarcTheSpark/scamp-tutor>`_).
