SCAMP AI Tutor

A do-it-yourself tutor for SCAMP (Suite for Computer-Assisted Music in Python). It works with whatever AI assistant you already use — Claude, ChatGPT, Gemini, or anything that can read a web page.

There's nothing to install. You just paste a short prompt that points the assistant at a set of instructions and the full SCAMP documentation and examples, all hosted here. The tutor is built to help you understand and own what you make — not to write your piece for you.

How to use it

Copy the prompt below into a fresh chat with your AI assistant. Replace the three numbers with your own experience levels (1 = none, 10 = expert) so it can pitch explanations at the right level, then start asking it to help you make music. 

Read https://raw.githubusercontent.com/MarcTheSpark/scamp-meta/main/scamp_tutor/instructions.txt. I want you to be my SCAMP tutor, using the instructions and resources described there. On a scale from 1-10, my experience levels are as follows: coding 5, python 4, music theory 7, scamp libraries 2.

Tip: adjust coding, python, music theory, and scamp libraries to match you. Be honest — it only changes how much gets explained, never what you're allowed to do.

What's here

The assistant fetches these as needed; you don't have to open them yourself.

  • instructions.txt — the tutor's instructions and a map of the resources below.
  • stumblingBlocks.txt — required reading for the assistant: SCAMP facts that AIs commonly get wrong.
  • docs/ — the SCAMP documentation, one text file per package.
  • examples/ — real, runnable SCAMP example scripts, plus an index.
